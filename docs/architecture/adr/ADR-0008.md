# ADR-0008: Bonus scope deferred beyond login milestone

**Status:** Accepted for milestone planning · **Baseline:** Devarom v1.3 · **Implementation verification:** not asserted by this documentation starter.

## Context

We need a maintainable, teachable, independently testable courier-delivery system with the assignment's security/integration and reporting requirements.

## Decision

Nov 1 prioritizes reviewed report and real logins. Kubernetes/Helm and authorized-tool AI Delivery Assistant are later bonus targets.

## Alternatives/trade-offs

Trying to implement every architectural option for Nov 1 reduces ability to demonstrate real auth.

## Consequences / implementation checks

Drawings can document targets; bonus claims require running evidence later.

**Revisit if:** human-approved architecture or assignment constraints change; record a replacement ADR and cross-team contract impacts.
