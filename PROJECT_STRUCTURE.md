# Repository structure (documentation-only starter)

```text
Devarom/
├── README.md, AGENTS.md, CLAUDE.md, GEMINI.md, PROJECT_STRUCTURE.md
├── .github/
│   ├── copilot-instructions.md
│   ├── PULL_REQUEST_TEMPLATE.md
│   └── ISSUE_TEMPLATE/{feature,bug_report}.md
├── .cursor/rules/devarom.mdc
├── .gitignore, .gitattributes, .editorconfig
├── frontend/README.md                        # SPA will be generated by team
├── services/
│   ├── api-gateway/README.md
│   ├── accounts-service/README.md
│   ├── pricing-service/README.md
│   ├── delivery-service/README.md
│   ├── communications-service/README.md
│   └── graphql-query-service/README.md
├── platform/{identity,local,kubernetes}/README.md
├── contracts/README.md                      # future reviewed machine-readable contracts
├── ai-assistant/README.md                   # optional bonus
├── tests/README.md
└── docs/
    ├── README.md
    ├── project/{PROJECT_CONTEXT,STATUS}.md
    ├── requirements/{ASSIGNMENT_SCOPE,DIAGRAM_TRACEABILITY}.md
    ├── requirements/assignment-traceability.csv
    ├── architecture/{BASELINE,PROTOCOL_MATRIX,DATA_OWNERSHIP,OPEN_DECISIONS}.md
    ├── architecture/adr/{README,ADR-0001..ADR-0008}.md
    ├── contracts/{README,REST,GRAPHQL,GRPC,KAFKA}.md
    ├── security/{AUTHENTICATION,AUTHORIZATION_MATRIX,THREAT_REVIEW}.md
    ├── team/{OWNERSHIP,MODULE_HANDOFF}.md, CONTRIBUTION_LOG.csv
    ├── milestones/{NOV_01,LOGIN_ACCEPTANCE,ROADMAP,REPORT_OUTLINE}.md
    ├── development/{GIT_WORKFLOW,DEFINITION_OF_DONE,CHANGE_POLICY}.md
    ├── ai/{TASK_TEMPLATE,PROMPT_PLAYBOOK,HANDOFF_TEMPLATE}.md
    └── diagrams/
        ├── README.md
        ├── editable/01..20_*.drawio
        └── rendered/01..20_*.svg
```

There are **no** application classes, `pom.xml`, `package.json`, frontend templates, `.proto`, Dockerfiles, Compose, Helm charts or CI workflows shipped. Placeholder directories can be filled with app-generated sources later by their named owners. ZIP extraction creates one enclosing folder; copy its **contents** into the root of the team's GitHub clone, rather than making a nested `Devarom/` inside the repository.
