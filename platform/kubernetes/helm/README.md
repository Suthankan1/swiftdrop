## 1. Executive Summary & Deliverables

Issue #149 delivers the enterprise-grade Helm chart foundation (`swiftdrop`), local TLS ingress configuration, least-privilege RBAC, and Kubernetes NetworkPolicy security boundaries for all eight approved runtime container images produced by Issue #128.

### Key Architectural Invariants
- **Immutable OCI Image Digests:** All eight microservice workloads reference cryptographically pinned image digests (`sha256:...`) from the private GitHub Container Registry (`ghcr.io`). Mutable `:latest` tags are strictly prohibited.
- **Embedded Ingress Controller:** Reuses the existing K3s embedded Traefik controller (`ingressClassName: traefik`). Zero additional reverse proxies, NGINX controllers, or service meshes are introduced.
- **Local TLS Boundary:** Full TLS termination at Traefik using an operator-provisioned Kubernetes Secret (`swiftdrop-tls-cert`) matching SANs `swiftdrop.local`, `*.swiftdrop.local`, `localhost`, and `127.0.0.1`.
- **Public vs. Internal Boundaries:** Only the React SPA (`frontend`), Spring Cloud API Gateway (`api-gateway`), and Keycloak Identity Provider (`keycloak`) are exposed via Ingress. All internal microservices (`accounts`, `pricing`, `delivery`, `communications`, `graphql`), gRPC ports, databases, Kafka, and MinIO remain strictly internal ClusterIP services.
- **Decoupled External Secrets:** Zero passwords, API tokens, or private keys are committed or generated by Helm templates. All credentials reference external Kubernetes Secrets (`secretKeyRef`).
- **Least-Privilege RBAC & Non-Root Execution:** All pods run as unprivileged non-root users (`UID 10001` for Java, `UID 101` for frontend, `UID 1000` for Keycloak) with dropped Linux capabilities (`ALL`) and `automountServiceAccountToken: false`.
- **Enforceable NetworkPolicies:** Implements default-deny ingress and egress across `swiftdrop-apps` and `swiftdrop-identity`, allowing only the precise traffic paths required by the approved communication matrix.
- **Strict $0 Cost Compliance (ADR-0011):** Zero Azure LoadBalancers, zero AKS, zero managed disks, zero paid DNS, and zero external cloud resources.

## 5. Ingress Routing, TLS & Browser Security Contract

### 5.1 Approved Browser-Facing Endpoints
The embedded Traefik Ingress Controller binds to host loopback ports `127.0.0.1:18080` (HTTP) and `127.0.0.1:18443` (HTTPS).

```text
                               +-----------------------------+
                               |     Local Browser / Curl    |
                               +-----------------------------+
                                              |
                          https://swiftdrop.local:18443
                                              v
                         +-----------------------------------+
                         |  K3s Traefik Ingress Controller   |
                         |  (TLS Termination via Secret)     |
                         +-----------------------------------+
                           /                 |               \
             Path: /api/**|    Path: /graphql|                | Path: /realms/**
             Path: /api/v1|                  |                | Path: /resources
                           v                 v                v
                 +-------------------+   +--------+   +-------------------+
                 | Spring Cloud      |   | Front- |   | Keycloak Identity |
                 | API Gateway       |   | end    |   | Provider (Quarkus)|
                 | (swiftdrop-apps)  |   | SPA    |   | (swiftdrop-ident) |
                 +-------------------+   +--------+   +-------------------+
                   /        |        \
            /api/v1/..   /api/v1/..  /api/v1/..
                  v         v         v
             +--------+ +--------+ +--------+
             |Accounts| |Pricing | |Delivery|
             +--------+ +--------+ +--------+
```

### 5.2 Server-Sent Events (SSE) Streaming Preservation
Delivery parcel tracking relies on long-running HTTP SSE streams (`/api/v1/tracking/**` and `/api/v1/parcels/**`).
- **Gateway Setting:** Spring Cloud Gateway configures `metadata.response-timeout: -1` on tracking routes.
- **Traefik Ingress:** Buffering is disabled for chunked transfer-encoding and `text/event-stream`.
- **Ingress Annotations:** No proxy buffering or short timeout annotations are applied.

### 5.3 Local Development TLS Certificate Trust
To trust the local development certificate chain without insecure flags (`curl -k`):
```bash
# 1. Generate local Root CA and leaf certificate for swiftdrop.local:
./platform/kubernetes/helm/scripts/generate-tls-secret.sh

# 2. Map swiftdrop.local in /etc/hosts:
echo "127.0.0.1 swiftdrop.local app.swiftdrop.local api.swiftdrop.local auth.swiftdrop.local" | sudo tee -a /etc/hosts

# 3. Test HTTPS with curl using the local CA:
curl -v --cacert ~/.swiftdrop/certs/swiftdrop-root-ca.crt https://swiftdrop.local:18443/health
```

### Strict Ownership & Isolation Invariants
- **Pricing cannot query Delivery DB.** Blocked by NetworkPolicy and DB user privileges.
- **Accounts cannot query Pricing DB.** Blocked by NetworkPolicy and DB user privileges.
- **Communications cannot query Delivery DB.** Blocked by NetworkPolicy and DB user privileges.
- **GraphQL API cannot query databases, Kafka, or MinIO directly.** Strictly limited to gRPC calls to Accounts and Delivery services.
- **Rogue / unauthorized pods cannot access gRPC, databases, Kafka, or MinIO.** Default-deny blocks all unauthorized traffic.

## 8. Host Capacity & Single-Node Limitations

- **Host Machine:** Apple Silicon ARM64 (10 physical cores, 16.0 GiB RAM).
- **Docker Desktop VM Allocation:** 4 CPUs, 4.06 GiB RAM.
- **Allocatable Memory:** ~4.06 GiB (4,262,272 Ki).
- **Foundation Footprint:** K3s control plane, CoreDNS, and Traefik consume ~668 MiB (16%).
- **Full-Stack Requirement:** Running all 8 application microservices concurrently with 5 PostgreSQL databases, Kafka KRaft, MinIO, and Mailpit requires **5.4 - 6.2 GiB RAM**.
- **Capacity Gate Status:**
  - `[PASS]` Helm Chart Foundations, Services, Ingress TLS, and NetworkPolicies: **VERIFIED**.
  - `[BLOCKED]` Full Concurrent Full-Stack Workload Deployment on 4.06 GiB Docker Desktop allocation: Requires operator to allocate >= 8 GiB RAM in Docker Desktop or use staged startup.
